6. 생기부 작성

좌측 메뉴에서 생기부 작성(Write) 탭을 선택합니다. 영역과 활동을 미리 설정해야 이 화면을 사용할 수 있습니다.

6-1. 화면 구성

실제 화면 — 생기부 작성(Write)

빠른 텍스트 교체 (🔍) 툴바 우측의 돋보기 버튼을 클릭하면 현재 영역 내에서만 텍스트를 즉석 검색·교체할 수 있는 창이 열립니다. 자세한 내용은 6-4를 참고하세요.

6-2. 내용 입력 및 자동 저장

  • • 그리드의 셀을 클릭하면 입력 모드가 됩니다. 바로 타이핑을 시작할 수 있습니다.
  • • 입력이 멈추면 자동으로 저장됩니다. 별도 저장 버튼은 없습니다.

6-3. 셀 히스토리

각 셀은 변경 이력이 누적 저장됩니다. 셀 하단 History를 클릭하면 이전 버전을 확인하거나 현재 문장을 저장할 수 있습니다.

  • • 히스토리 목록 상단에 현재 작성 중인 내용이 현재 버전 카드로 표시됩니다.
  • • 이전 버전을 클릭하면 해당 시점의 내용으로 되돌릴 수 있습니다.
  • • 메모를 입력하여 중요한 버전을 수동으로 저장할 수 있습니다.
💡

큰 수정이 예정된 경우 먼저 스냅샷을 생성해두면 DB 전체를 이전 상태로 되돌릴 수 있습니다. 스냅샷은 좌측 사이드바 하단 스냅샷 탭에서 생성합니다.

6-4. 빠른 텍스트 교체

툴바 우측의 🔍 돋보기 버튼을 클릭하면 현재 선택된 영역 내에서만 텍스트를 즉석으로 검색하고 일괄 교체할 수 있는 창이 열립니다.

사용 순서

  1. 1 찾을 내용에 검색어를 입력하고 검색 버튼을 클릭합니다.
  2. 2 검색어가 포함된 학생·활동 목록과 교체 전후 미리보기가 표시됩니다.
  3. 3 바꿀 내용을 입력하고 미리보기를 확인한 뒤 교체 적용 버튼을 클릭합니다.

텍스트 치환(Replace)과의 차이

빠른 텍스트 교체 텍스트 치환(Replace)
적용 범위 현재 선택된 영역만 DB 전체 (모든 영역·활동)
규칙 저장 저장 없음 (1회성) 규칙으로 저장하여 재사용 가능
⚠️

교체 적용은 되돌릴 수 없습니다. 적용 전 미리보기를 반드시 확인하거나 스냅샷을 먼저 생성해두세요.

6-5. 모달 공통 단축키

  • • 셀 히스토리, 빠른 텍스트 교체, 스냅샷 등 모든 모달 창은 ESC 키로 닫을 수 있습니다.
